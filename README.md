# Yandex Music Rust

Нативный неофициальный клиент Яндекс Музыки для Windows. Главное преимущество — низкое потребление оперативной памяти: без Electron и WebView, с виртуальным списком треков, кэшем до 40 обложек и дисковыми аудиобуферами. Текущий и следующий треки не удерживаются целиком в RAM; временные файлы удаляются при закрытии дескриптора. В минутной проверке release 0.2.2 после запуска «Моей волны» пик рабочей памяти составил 89 МиБ, выделенной памяти процесса — 96 МиБ. Это замер конкретного запуска, а не жёсткий лимит для любой конфигурации Windows.

- Поиск, любимые треки, плейлисты и карточки исполнителей.
- Моя волна, рекомендации и карточки ближайших треков.
- Потоковое воспроизведение, отдельная предзагрузка следующего трека, MP3 и lossless.
- Трей: открыть, играть/пауза, следующий трек, выход. Крестик скрывает окно; выход — через трей.
- Discord RPC: тип «Слушает», песня, исполнитель, обложка, время и ссылки. Приоритет параллельных активностей зависит от Discord. Название статуса выбирается в настройках; поддержка отображения полей зависит от версии Discord.
- Эквалайзер, медиаклавиши, мини-плеер и MCP.

## Запуск

Скачайте `yandex-music-rust.exe` и запустите. Дополнительный MCP EXE и файлы иконок не нужны. Для полного доступа к музыке нужны аккаунт и действующая подписка Яндекс Плюс.

Вход — в настройках через Яндекс ID. «Запомнить» хранит токен в Windows Credential Manager в профиле текущего пользователя и сохраняет его между входами в Windows. Не передавайте токен и MCP-конфигурацию другим людям.

## Сборка

```powershell
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked --release
```

Результат: `target/release/yandex-music-rust.exe`. Требуются Rust stable и Visual Studio Build Tools с Windows SDK.

## MCP

В настройках скопируйте конфигурацию MCP. Она запускает тот же EXE с `--mcp`, портом и ключом в переменной окружения `YANDEX_MUSIC_MCP_KEY`. Плеер должен работать; после перезапуска скопируйте новую конфигурацию. Доступны состояние, поиск, очередь, управление воспроизведением, любимое, плейлисты и волна.

## Интерфейс

Сердце переключает отметку «нравится» и подсвечивается после подтверждения сервера. На карточке активного трека кнопка меняется на паузу. Клик по обложке или названию открывает подробный экран с плавным градиентом из цветов обложки. ПКМ по треку открывает добавление в плейлист и создание нового личного плейлиста.

В настройках Discord можно выбрать заголовок (приложение, артист, артист — трек, трек), русский или английский язык кнопок и включить ссылки. Выбор сохраняется между запусками. Обычное окно имеет минимальный размер 560×480, мини-плеер — 560×210.

## Ограничения

Неофициальный API может меняться. «Любимое» показывает последние 100 треков. Кнопка RPC «Открыть в приложении» использует протокол `yandexmusic://` и требует зарегистрированного обработчика. Отображение RPC и кнопок проверяйте с другого аккаунта Discord.
