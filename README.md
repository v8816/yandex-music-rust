# Яндекс Музыка · Rust

Нативный прототип клиента для Windows x64. Интерфейс egui, API, воспроизведение, Discord RPC и MCP написаны на Rust. Исходное оформление послужило ориентиром для тёмной темы, жёлтого акцента, боковой навигации и панели плеера. Проект основан на разборе [YandexMusicModClient 67f49fd](https://github.com/TheKing-OfTime/YandexMusicModClient/tree/67f49fdd75c74adbe83e96d3e18f807084fb58a8).

## Запуск

Возьмите готовые файлы из раздела Releases на GitHub или соберите проект (см. «Сборка»), затем откройте `yandex-music-rust.exe`. Держите `yandex-music-mcp.exe` в той же папке. Поиск запускается по мере ввода и работает без входа. Обложки загружаются в фоне и видны в списках и плеере. Чтобы открыть поиск с клавиатуры, нажмите Ctrl+K.

Для входа нажмите «Войти в Яндекс ID» в меню, затем «Войти через Яндекс ID». Подтвердите доступ на странице Яндекса в браузере. После перехода на Яндекс Музыку скопируйте адрес целиком (Ctrl+L, Ctrl+C), вернитесь в клиент и вставьте его в поле входа. Клиент проверит адрес и завершит вход. Вставляйте эту ссылку только в клиент, так как в ней содержатся данные входа.

С флажком «Запомнить меня на этом ПК» сессия хранится в Диспетчере учётных данных Windows. Клиент подхватывает её при запуске и удаляет при выходе из аккаунта. Ручной ввод OAuth-токена доступен в «Другой способ входа». Для запуска из скрипта можно использовать `YANDEX_MUSIC_TOKEN`. MCP не получает данные авторизации.

Клиент использует неофициальный API Яндекс Музыки. Если сервис откажет в доступе или вернёт несовместимый формат, клиент покажет ошибку. Для lossless есть настройка запроса FLAC. Доступность формата зависит от ответа сервиса.

На главной нажмите «Моя волна», чтобы начать персональный поток с аккаунта. Очередь пополняется при достижении конца подборки. Через MCP для запуска доступна команда `wave_start`, а для паузы и переключения подходят обычные команды плеера.

Иконка с тремя ползунками в нижней панели открывает эквалайзер. Он также доступен в «Настройки → Воспроизведение». Пять полос можно менять от −12 до +12 дБ, не перезапуская трек. Флажок «Включён» позволяет сравнить звучание с исходным. Настройки действуют до закрытия клиента. MCP-команда `equalizer` принимает `enabled` и массив `gains` для частот 60, 250, 1000, 4000 и 12000 Гц.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Пробел | Плей/пауза |
| Ctrl+→ / Ctrl+← | Следующий / предыдущий трек |
| Ctrl+Shift+→ / Ctrl+Shift+← | Перемотка на ±10 секунд |
| Ctrl+↑ / Ctrl+↓ | Громкость ±5 % |
| Ctrl+K | Поиск |
| Ctrl+= / Ctrl+- / Ctrl+0 | Масштаб интерфейса |

Комбинации работают, пока фокус не в поле ввода, поэтому набор текста в поиске не переключает треки.

## Мультимедийные клавиши

Клавиши плей/пауза, следующий и предыдущий трек перехватываются глобально и работают, даже когда окно свёрнуто. Отключаются в «Настройки → Воспроизведение». Если клавиши уже заняты другим плеером, клиент забирает их низкоуровневым хуком клавиатуры, который срабатывает раньше чужих обработчиков; при отключении настройки клавиши возвращаются системе.

## Скорость переключения

Трек начинает играть, не дожидаясь полной загрузки: клиент скачивает начало файла (256 КБ) и запускает декодер, а остаток докачивается в фоне. Если формат требует конец файла (например, mp4), клиент сам переходит на полную загрузку. Аудио грузится отдельным потоком, поэтому интерфейс и команды плеера не ждут сеть, устаревшая загрузка отменяется при выборе другого трека, а следующий трек очереди скачивается заранее — переключение по «дальше» обычно происходит сразу. Пока трек ещё не готов, в нижней панели видно «Загрузка трека…», перемотка в этот момент недоступна.

## Об исполнителе

Имя исполнителя в списке треков (в поиске, плейлистах, очереди) и под плеером — ссылка: нажмите на него, чтобы открыть страницу артиста с обложкой, статистикой, описанием и популярными треками. Кнопка «← Назад» возвращает на предыдущую страницу.

## Плейлисты профиля

На странице «Плейлисты» (требуется вход в аккаунт) показаны ваши подборки из Яндекс Музыки с обложками. Нажмите «Обновить», чтобы загрузить список, а затем «Играть» под нужным плейлистом — очередь заменится на его треки и начнётся воспроизведение.

Чтобы посмотреть, что внутри, нажмите «Открыть» (или кликните по названию): откроется страница плейлиста с обложкой, владельцем, числом треков и полным списком — любой трек можно включить или добавить в очередь. Кнопка «← Плейлисты» возвращает к списку. Так же открывается «Мне нравится»: его содержимое берётся из списка любимых, поэтому там видны все отмеченные треки.

## Громкость

Ползунок громкости работает по логарифмической шкале (от −60 до 0 дБ) вместо линейной 0..=1. Это соответствует человеческому слуху: тихие значения действительно тихие, и даже при минимальной громкости музыка не будет звучать слишком громко. Подпись рядом с ползунком показывает положение ручки в процентах, поэтому она всегда совпадает с самим ползунком, а крайнее левое положение полностью выключает звук. Точное значение в дБ видно в подсказке при наведении.

## MCP

1. В клиенте откройте «Настройки» и включите управление MCP.
2. Нажмите «Скопировать конфигурацию MCP». Вставьте её в настройки вашего MCP-клиента. Для клиентов с другим форматом конфигурации используйте те же значения `command` и `args`, транспорт stdio.
3. Держите музыкальный клиент открытым. После его перезапуска или повторного включения MCP скопируйте новую конфигурацию.

Агент может читать состояние, искать и запускать треки по запросу или ID, управлять очередью, ставить на паузу и возобновлять, переключать треки, перематывать, менять громкость и режимы повтора, ставить и снимать лайки, читать до 100 любимых треков, открывать плейлисты профиля и их треки (`playlists`, `playlist_tracks`), смотреть данные исполнителя (`artist`), а также переключать lossless, перемешивание и Discord RPC. Вход и выдача доступа MCP выполняются вручную в окне. Канал управления слушает только локальный адрес и требует случайный ключ текущего сеанса.

## Сборка

Из этой папки в PowerShell, с Rust и инструментами Visual Studio C++ для MSVC:

```powershell
cargo build --locked --release
cargo test --locked
cargo test --locked --lib public_search_through_bridge -- --ignored
cargo test --locked --lib api::tests::public_playlists -- --ignored
cargo test --locked --lib media::tests -- --ignored
```

Два исполняемых файла окажутся в `target/release`. Последние три команды отдельно проверяют публичный поиск через живой API, выдачу плейлистов и их треков, а также захват мультимедийных клавиш (на время теста они отбираются у системы).

## Состояние переноса

- Перенесены базовый плеер, поиск с обложками, очередь, любимые треки, запуск Моей волны, компактный режим поверх окон, масштаб и базовый Discord Rich Presence.
- Полное воспроизведение из аккаунта, запись лайков, lossless и отображение статуса в Discord требуют отдельной проверки с авторизацией. Поиск через MCP и отзыв доступа при выключении проверены.
- Полный паритет ещё требует настроек Моей волны, плейлистов и других разделов каталога, офлайн-кэша, экспорта в файл, Last.fm, глобальных горячих клавиш, управления с других устройств, расширений панели задач и прочих настроек оригинального RPC.
- Сетевые операции идут в рабочем потоке, HTTP-клиент переиспользуется, интерфейс обновляется по событиям, а аудиоустройство открывается при начале воспроизведения. Сейчас клиент загружает файл целиком с ограничением размера. Сравнительных замеров с Electron нет.
